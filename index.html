Diskokugeln für eine FestivalbühneMirror balls for a festival stage

Die Kugeln sitzen auf höhenverstellbaren Tischbeinen, also Linearantrieben von rund einem Meter, und drehen sich über eigene Motoren. Ich habe alles selbst verkabelt und programmiert. Die Firmware läuft auf einem ESP32 und empfängt vier DMX-Kanäle: Höhe, Fahrgeschwindigkeit, Drehung und Programm.

Endschalter gibt es keine. Die Firmware erkennt die Endlagen am Motorstrom und misst in einem Kalibrierlauf selbst, wie lange der Antrieb für den ganzen Weg braucht. Eingestellt wird über eine Weboberfläche im eigenen WLAN des ESP32. Die Steuerlogik ist reines C++ und läuft in Unit-Tests auf dem Rechner, ganz ohne Hardware.

The balls sit on height-adjustable table legs, linear actuators about a metre long, and each rotate on their own motor. I wired and programmed it myself. The firmware runs on an ESP32 and receives four DMX channels: height, travel speed, rotation and program.

There are no limit switches. The firmware detects the end stops from the motor current and measures in a calibration run how long the actuator needs for the full stroke. Settings are changed through a web interface on the ESP32's own WiFi. The control logic is plain C++ and runs in unit tests on a computer, without any hardware.

ESP32, C++, PlatformIO, FreeRTOS, DMX512
